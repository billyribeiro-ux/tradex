# App icons

These were generated from the brand SVG with the Tauri CLI:

```sh
pnpm tauri icon static/icon.svg
```

Re-run that command after changing `static/icon.svg` to regenerate the full set
(`32x32.png`, `128x128.png`, `icon.ico`, `icon.icns`, plus Android/iOS assets)
referenced by `tauri.conf.json`.
